# Wettbewerb

| Lösung | Ansatz | OLED-tauglich? | Notiz |
|---|---|---|---|
| [[Dark Reader Analyse\|Dark Reader]] | Dynamic/Filter/Static | teilweise | `#000` einstellbar, Ebenen bleiben grau, dunkle Seiten unangetastet |
| Chrome „Auto Dark Mode for Web Contents“ (`chrome://flags`) | Browser-intern, Invertierung | eher nein | Experimentell, keine Kontrolle über Werte |
| Native Dark Modes der Seiten | Seiten-CSS | meist nein | Typisch `#121212`–`#1e1e1e` (Material Design) |
| Diverse „Night Eye“-/„Midnight“-Erweiterungen | meist Filter/kommerziell | gemischt | Teils Abo-Modelle, teils Tracking-Bedenken |
| User-Styles (Stylus + OLED-Themes) | Handgeschriebenes CSS je Seite | ja | Hoher Pflegeaufwand, nur einzelne Seiten |
