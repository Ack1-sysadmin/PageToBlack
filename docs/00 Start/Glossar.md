# Glossar

- **ABL** – Automatic Brightness Limiter; OLED dimmt bei großen hellen Flächen. → [[OLED Grundlagen]]
- **ADR** – Architecture Decision Record; dokumentierte Entscheidung in `04 Entscheidungen`.
- **Blackening** – Unser Modus, der bereits dunkle Seiten auf echtes `#000` bringt. → [[Rendering-Modi]]
- **Burn-in** – Dauerhaftes Einbrennen statischer Bildinhalte ins Panel.
- **Content Script** – Skript der Erweiterung, das im Kontext einer Webseite läuft.
- **CORS** – Cross-Origin-Schutz; verhindert Lesen fremder Stylesheets per CSSOM.
- **CSSOM** – CSS Object Model, programmatischer Zugriff auf Stylesheets.
- **FOUC / Weißblitz** – Kurzes Aufblitzen der hellen Originalseite vor dem Umfärben.
- **MV3** – Chrome Manifest V3. → [[Chrome Manifest V3]]
- **Near-Black** – Sehr dunkle Grautöne knapp über Schwarz; auf OLED oft unruhig.
- **OKLCH** – Wahrnehmungsnaher Farbraum (Helligkeit, Chroma, Farbton). → [[Farbalgorithmus]]
- **QD-OLED / WOLED** – OLED-Bauarten (Samsung bzw. LG) mit unterschiedlichen Subpixel-Layouts.
- **Site-Fix** – Seitenspezifische Korrektur (Selektoren/CSS) für Problemseiten.
