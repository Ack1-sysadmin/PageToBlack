## Nachtest: Text zu grau (Feedback Projektinhaber)
- **Befund:** Auf hellen Seiten war Text eher grau als weiß. GitHub „Light default“, instservice.gsd-software.com (`#666`-Text → `#878787`).
- **Ursache:** Die Kurve hat nach dem Invertieren linear um 12 % gedimmt. Helle Seiten nutzen selten reines Schwarz als Text, das Ergebnis lag deutlich unter dem, was Dark-Themes für Text verwenden.
- **Fix:** Ease-out-Kurve, die Text anhebt, plus Umkehrkurve für Medien (siehe [[Rendering-Modi]]). Unit-Tests (`npm test`) sichern die Kurve ab, E2E um einen `#666`-Test erweitert.

| Textfarbe (Original) | vorher | nachher |
|---|---|---|
| `#000` | `#e0e0e0` | `#f0f0f0` |
| `#1f2328` (GitHub) | ≈ `#c5c2bd` | ≈ `#e8e8e8` |
| `#666` (instservice) | `#878787` | ≈ `#c0c0c0` |

- Weiterhin offen: Die dunkle Kopfleiste von GitHub (helles Theme) wird invertiert jetzt noch heller → M1 (`prefers-color-scheme` erzwingen). Dunkle Logos mit transparentem Hintergrund (z. B. „inst“-Schriftzug bei instservice) bleiben dunkel auf Schwarz.

### Feinjustierung
Projektinhaber: „Etwas heller wäre noch gut.“ → `textMax` 0,94 → **0,97**. `#000` → `#f7f7f7`, GitHub `#1f2328` → ≈ `#f3f3f3`, `#666` → ≈ `#cccccc`. Damit bestätigt.
