# ADR-0003: MIT-Lizenz

## Kontext
Das Repository ist öffentlich. Dark Reader, unsere wichtigste Referenz, steht ebenfalls unter MIT.

## Entscheidung
PageToBlack wird unter der **MIT-Lizenz** veröffentlicht (`LICENSE` im Repo-Root).

## Konsequenzen
- Code darf frei genutzt und weiterverbreitet werden, auch kommerziell
- Übernommene Dark-Reader-Stücke sind lizenzkompatibel; deren Copyright-Hinweis wird im Code und in `THIRD_PARTY_NOTICES` mitgeführt
